### UT01: Elementos y las herramientas que intervienen en el desarrollo de una aplicación informática, análisis de características y fases de desarrollo.

a) Componentes básicos de un sistema informático necesario para el desarrollo de software.

b) Concepto de software. Historia y orignes del desarrollo de sofware.

c) Concepto de aplicación informática. Fases de desarrollo de una aplicación informática.

d) Lenguajes de programación: conceptos de código fuente, código objeto y código ejecutable.

e) Proceso de obtención de código código intermedio para su ejecución en máquinas virtuales a partir del código fuente. Herramientas implicadas: editores, compiladores, enlazadores, etc.

f) Clasifiación de los lenguajes de programación: Lenguajes compilados , interpretados y virtuales. Código máquina. Lenguajes de medio y alto nivel.

g) Herramientas utilizadas en el desarrollo de aplicaciones web. Herramientas CASE.
